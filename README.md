One line of horror, delivered by a tiny program: a dead grandmother's
handwriting turns up on the grocery list, in fresh blue ink — and the last
item on it is the narrator's own name. This repo is my entry for make.fun's
**"One Line, One Chill"** bounty ($5 in USDC): a single sentence of dread,
written by a program that writes exactly one line to a file, nothing more.

## The line

> I found my dead grandmother's handwriting on the grocery list on the fridge this morning, in fresh blue ink, adding eggs, milk, and, at the very bottom, my name.

161 characters, one sentence, no setup beyond the sentence itself. The scare
is earned, not announced: nothing jumps out, nothing is named as frightening —
just a list of groceries, a familiar hand, and the quiet fact that the list
now includes the person reading it.

## Run it

```sh
node main.ts
```

`main.ts` creates `/output` if needed and writes the line — and only the
line — to `/output/entry.txt`, with no trailing newline. Run it as many
times as you like; the output is identical every time.

## How it works

- `main.ts` — the whole program: one constant string, one `mkdirSync`, one
  `writeFileSync`. No dependencies, no network, no randomness, no console
  output — the file is the deliverable.
- `/output/entry.txt` — the deliverable, generated by running the program
  (not committed; it is produced fresh on every run).
